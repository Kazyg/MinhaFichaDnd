# Diretório legado

A aplicação ativa é uma SPA React 18 com React Router e react-scripts, na raiz deste repositório. Este diretório não é uma aplicação Next.js executável.

Execute `npm ci` e `npm start` na raiz. Consulte o [README principal](../README.md) para persistência, funcionalidades e limitações por edição e a [verificação](../docs/VERIFICACAO.md) para testes, lint, tipos e build seguro.
